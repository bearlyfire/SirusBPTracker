# \# SirusBPTracker

# 

# Удобный пользовательский трекер Боевого Пропуска для игрового сервера Sirus

# 

# \## 🚀 Установка

# 1\. Нажмите зеленую кнопку \*\*Code\*\* в правом верхнем углу этой страницы и выберите \*\*Download ZIP\*\*.

# 2\. Распакуйте архив.

# 3\. Переименуйте извлеченную папку из `SirusBPTracker-main` просто в `SirusBPTracker`.

# 4\. Перенесите папку в директорию игры: `World of Warcraft\\Interface\\AddOns\\`.

#

# Модификация полностью бесплатна и создается на добровольных началах. Если аддон вам помог и вы хотите отблагодарить автора, вы можете сделать это двумя безопасными способами:

#
