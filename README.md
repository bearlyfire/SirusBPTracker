# SirusBPTracker

Удобный пользовательский трекер Боевого Пропуска для игрового сервера Sirus

## 🚀 Установка
1. Перейдите в раздел [Релизы (Releases)](https://github.com/bearlyfire/SirusBPTracker/releases) в правой части этой страницы.
2. Скачайте чистый архив `SirusBPTracker.zip` из самого свежего релиза.
3. Распакуйте архив напрямую в папку игры: `World of Warcraft\Interface\AddOns\`.

## ☕ Поддержать проект
Модификация полностью бесплатна и создается на добровольных началах. Если аддон вам помог и вы хотите отблагодарить автора, вы можете сделать это двумя безопасными способами:

* **В игре:** Отправить внутриигровое золото на почту персонажу **Медведж** на реалме **[SIRUS_x5]**.
* **Напрямую:** Оставить произвольную сумму в качестве подарка на развитие через [сервис CloudTips] (https://pay.cloudtips.ru/p/aff01756).
